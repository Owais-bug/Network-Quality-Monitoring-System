
# Network Quality Monitoring System

A web-based application designed to monitor website and server availability, response time, and network service health.

## Project Goals

- Monitor authorized websites and servers.
- Measure response time.
- Identify UP, SLOW, and DOWN statuses.
- Maintain monitoring history and events.
- Display monitoring information through a dashboard.

## Technology Stack

- Frontend: React, Vite, HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MySQL
- Version Control: Git and GitHub

## Project Structure

- `frontend/` — React dashboard
- `backend/` — Server and monitoring APIs
- `database/` — Database scripts and schema
